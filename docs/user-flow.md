# GrowWhere — сценарій користувача MVP

Статус: **рання пропозиція для обговорення** (2026-11-14).  
Актуальний реалізований сценарій із двома входами та п’ятьма кроками описано в [parcel-workflow.md](parcel-workflow.md). Нижче збережено ранню продуктову пропозицію, а не поточну специфікацію екранів.
Основа — [вимоги команди](mvp.md). Послідовність «що → де → як» та роль
карти задані командою; конкретні поля, кнопки й обмеження нижче запропоновані.

## Основний шлях

Вступ → регіон і умови → порівняння культур → культура → карта придатності
→ територія → пояснення й економіка → порівняння альтернатив → підсумок.

### 1. Перший вхід: зрозуміти користь

- Користувач бачить логотип GrowWhere, карту світу з не більш ніж вісьмома регіонами та компактну вступну панель.
- Обіцянка: «Оберіть культуру й знайдіть, де її вирощувати, з урахуванням ґрунту, клімату та економіки».
- На панелі можна задати регіон, період оцінювання та доступність зрошення. Регіон США й доступний період можна підставити як видимі початкові значення; користувач може їх змінити.
- Кнопка «Дослідити регіон» веде до робочої карти; «Спробувати приклад» відкриває позначений демонстраційний сценарій із наперед заданими умовами.
- Реєстрація для цього сценарію не потрібна. Вступну панель можна закрити й відкрити повторно.

### 2. Регіон і початкові умови

- На карті активний лише обраний для MVP регіон США; для інших — «Незабаром», без переходу до вигаданого аналізу.
- Клік по активному регіону наближає карту, показує межу доступного покриття й бічну панель.
- Поля початкових умов: `регіон`; `період` зі списку підтримуваних даними; `зрошення` — доступне / недоступне / невідомо.
- Додатково: бюджет вирощування на одиницю площі. Пропозиція для порівняння — USD/га, із явним перерахунком вихідних одиниць. Власну культуру чи площу на вході не вимагаємо.
- Період описує основу оцінки; історичний набір не показується як прогноз погоди майбутнього сезону. Для економічних даних окремо видно їхній рік/дату.
- Якщо користувач не знає умов, можна продовжити з видимими припущеннями або невідомими значеннями. Невідоме зрошення не перетворюється на «доступне».

### 3. Що вирощувати: початкове порівняння

- Бічна панель показує невеликий перелік підтримуваних культур; для MVP пропонується 3–5, конкретний список ще не визначено.
- Картка містить назву, коротке пояснення регіональної придатності, орієнтир витрат на одиницю площі, ціну продажу й доступні ринкові тенденції.
- Це регіональний огляд: придатність окремих зон може різнитись. Точне число балів або відсоток не додаємо без визначеної методики.
- Можна сортувати за придатністю або доступною оцінкою витрат. Дані з різним складом витрат чи несумісними періодами не ранжуємо як рівнозначні.
- Кнопка «Показати на карті» обирає культуру й вмикає відповідний шар. Єдина «найкраща» культура не оголошується без визначених критеріїв користувача та методики.

### 4. Де вирощувати: дослідження карти

- Для вибраної культури й поточних умов карта показує зелений — придатно; червоний — непридатно. Додатково пропонуються жовтий — придатно за умов; сірий — недостатньо даних.
- Легенда містить текстові значення. Вибір території має окремий контур і не змінює значення аналітичного кольору.
- Для MVP пропонується клік по готовій зоні аналізу в активному покритті. Малювання довільних меж можна додати пізніше. Зону аналізу не називаємо точним контуром господарського поля без відповідних даних.
- При виборі зони карта зберігає шар культури, підсвічує контур і відкриває результат саме для цієї території.
- Вибір іншої культури або умов оновлює шар і пояснення. Під час оновлення попередній результат не показується як результат нового запиту.

### 5. Як вирощувати: результат для території

Бічна панель містить три блоки:

1. **Придатність.** Підсумок для культури й зони, ключові чинники ґрунту та клімату, період, джерела й обмеження деталізації.
2. **Умови вирощування.** Пояснення того, які умови підтримують результат, що його обмежує та які доступні параметри можна змінити. Конкретні агрономічні дії й сезонні вікна — тільки якщо їх підтримує реалізована методика.
3. **Економіка.** Витрати й їхній склад, ціна продажу, доступні обсяги/рух продукції та тенденції. Для кожного показника — географія, одиниці, дата, джерело й статус оцінки. Регіональні витрати не стають польовими вимірюваннями після кліку на карту.

На першому етапі достатньо витрат на одиницю площі та ціни на одиницю продукції.
Загальний бюджет потребує визначеної площі, а розрахунок маржі — сумісної
врожайності, ціни та витрат. Якщо їх немає, підсумковий прибуток не розраховується.

### 6. Порівняти альтернативи

- Для вибраної території можна переключити культуру або обрати до трьох культур для компактного порівняння в бічній панелі.
- Порівнюються придатність, основні обмеження, витрати, ціни та доступні ринкові показники. Періоди й одиниці видно; прогалини не підміняються нулями.
- Одночасно на карті активний один шар культури. Перемикання культури зберігає територію та початкові умови.
- Зміна зрошення або бюджету оновлює лише ті результати, які залежать від цього параметра. Невідомі витрати не дають змоги підтвердити відповідність бюджету.
- Якщо придатних культур немає, показати причини й доступні способи змінити умови або територію; не пропонувати довільну «найкращу» культуру.

### 7. Підсумок вибору

- Кнопка «Підсумок» показує на тій самій карті вибрану територію, культуру, умови, придатність, економічні орієнтири та головні обмеження.
- Користувач може повернутись до параметрів і порівняння без повторного заповнення всього сценарію.
- Експорт, особистий кабінет і збереження між відвідуваннями не потрібні для запропонованого першого наскрізного демосценарію.

## Додатковий вхід: територія вже відома

На робочій карті користувач може спочатку обрати зону, а потім побачити культури
для неї. Це той самий сценарій з попередньо вибраною територією; решта кроків
і формат результату не змінюються. Додаткова стартова анкета для цього не потрібна.

## Склад постійного інтерфейсу

- Верхня панель: логотип, активний регіон, повернення до огляду світу, довідка.
- Карта: покриття, шар активної культури, контур території, легенда, масштабування.
- Бічна панель: умови → культури → результат/порівняння; поточні параметри завжди доступні для редагування.
- Метадані біля результату: дата й період даних, географія економічної оцінки, позначка demo за потреби.

## Стани, які потрібно передбачити

| Ситуація | Що бачить користувач |
| --- | --- |
| Дані завантажуються | Видимий стан завантаження, параметри поточного запиту |
| Помилка отримання | Пояснення та повторна спроба; відсутня підміна демонстраційними значеннями |
| Немає даних для зони | Сірий стан і перелік того, чого бракує |
| Немає економічних показників | Придатність доступна, відповідні економічні поля позначені як відсутні |
| Показники мають різні періоди | Дати й обмеження порівняння видимі |
| Регіон не підтримується | «Незабаром» і можливість перейти до доступного регіону США |

## Мінімальна демонстрація

Користувач проходить від вступу до культури, змінює параметр, бачить карту
придатності, обирає зону, читає пояснення та порівнює альтернативу з економічними
показниками або явними прогалинами. Усі демонстраційні дані позначені.
Точний регіон, культури, період та правила оцінки визначаються окремо.
