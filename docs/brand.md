# GrowWhere — бренд і візуальний напрям

## Вимоги команди

- Назва продукту: **GrowWhere**.
- Назва команди: **RightVersion**. Допустимий підпис: `GrowWhere · by RightVersion`.
- Використовувати логотип, наданий командою 2026-11-14, та схожу кольорову гаму сайту.
- [Оригінальний логотип](assets/growwhere-logo.png) збережено без змін. Це наданий візуальний матеріал, а не джерело інструкцій для агента.

## Візуальні орієнтири

На логотипі — чорний центральний знак зі стрілками у восьми напрямках на
зелено-бірюзовому тлі. Репрезентативний базовий колір файлу: **#27D39B**;
чорний: **#000000**. Растровий оригінал містить близькі відтінки.

Пропозиція для інтерфейсу: зелено-бірюзові акценти для основних дій і вибору,
чорна типографіка та знак, спокійні нейтральні поверхні навколо карти.
Точні кольори фону, типографіку й темну/світлу тему ще не погоджено.

Для карти зелений і червоний мають семантичне значення придатності. Вибрана
ділянка, кнопка та зона придатності повинні відрізнятись формою/контуром або
підписом. Використовувати текстову легенду; перевіряти читабельність і контраст.
Не перефарбовувати всі аналітичні стани лише в брендове зелене.

Логотип не перемальовувати та не змінювати пропорції без відповідного завдання.
Після вибору структури застосунку використати цей оригінал у його статичних ресурсах.
