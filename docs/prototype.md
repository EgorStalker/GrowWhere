# GrowWhere — перший інтерактивний макет

**Історичний опис версії 0.1.** Поточна активна версія 0.2 використовує реальну
карту, серверний API й отримані набори: [актуальний стан](live-data-integration.md).
Нижченаведені демонстраційні дані й знімки описують лише попередню версію.

Дата: 2026-11-14. [Код і запуск](../apps/web/prototype/README.md).

## Прямі вимоги команди

- Перша версія українською; фінальну версію згодом перекласти англійською.
- Інтерфейс для людей із невеликим досвідом користування сайтами й сучасними ІТ.
- Зробити макет, який можна розвивати далі; зберегти попередні вимоги карти, бренду й економічного порівняння.

## Реалізовані рішення макета

- Три видимі кроки: «Ваш регіон» → «Що вирощувати» → «Де вирощувати».
- Великі кнопки, пояснення звичайними словами, постійна довідка, режим A+.
- Вісім схематичних регіонів світу; активний приклад Центральних рівнин США.
- Три культури й шість схематичних зон; клік по карті або рівнозначний вибір зі списку.
- Зміна поливу, бюджет, економічні орієнтири, порівняння й підсумок вибору.
- Для телефону порівняння показується окремими картками; для великого екрана — таблицею.
- Підписи кольорів, клавіатурне керування зонами, видимий фокус, повідомлення про зміну стану, семантичні діалоги.
- Сірий стан для відсутніх даних; demo-позначки; обробка недоступної базової карти з можливістю продовжити зі списку.
- Український словник відділено від логіки; майбутній англійський переклад не потребує переписування сценарію.

Центральні рівнини, три культури та числа обрані лише для демонстрації
взаємодії. Повноцінну методику, остаточний регіон та аналітичні інтеграції
ще не реалізовано. Зручність для цільової аудиторії потребує перевірки
з реальними користувачами; виконані технічні перевірки цього не замінюють.

## Перевірки

- Чотири перевірки моделі прикладу: відсутні вимірювання, вплив поливу,
  порівняння бюджету, назви та доступність регіонів.
- Перевірено в браузері основний шлях, список зон, зміну культури та поливу,
  бюджет, порівняння, підсумок, довідку, відсутність даних і збільшення тексту.
- Вибір зони клавішею Enter перевірено; помилок і попереджень у консолі під час основних сценаріїв не виявлено.
- Перевірено великий екран і телефон; на телефоні виправлено вихід індикатора кроків за межі екрана.

## Перегляд

[Автономний макет](../apps/web/prototype/growwhere-preview.html) можна відкрити
у браузері без запуску сервера. Він генерується командою `npm run export`.
Для автономного файлу перевірено структуру й синтаксис; вбудований браузер
Codex не дозволив відкрити локальну адресу `file:`, тому окремий запуск цього
файлу в ньому не перевірено. Модульну версію перевірено через локальний сервер.
Онлайн-публікацію зупинено після відмови автоматичної перевірки зовнішньої
передачі коду до Sites; для неї потрібен окремий дозвіл користувача.
