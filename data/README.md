# Дані RightVersion

## Поточна наявність

Є каталог 24 позицій із наданого командою тексту та додаткове джерело USDA ERS.
**Реальні відповіді POWER, SSURGO, CDL та ERS вже отримано.**
Додано актуальний NOAA NWS hourly forecast для точки й частковий реєстр
перевірених K-State правил. Прогноз має окрему перевірку часу випуску/дії;
рекомендації дати й поливу ще заблоковано критичними прогалинами.
[catalog/datasets.json](catalog/datasets.json) обліковує сирі артефакти з URL,
параметрами, часом отримання й SHA-256. Каталог джерел не замінює цей реєстр.
Пайплайн: `pipelines/growwhere/`; контракт API та правила оновлення — у
[live-data-integration.md](../docs/live-data-integration.md).

| Шлях | Вміст |
| --- | --- |
| [catalog/sources.csv](catalog/sources.csv) | Доступні для дослідження джерела, переказ наданого тексту |
| [catalog/additional-sources.csv](catalog/additional-sources.csv) | Додаткові перевірені джерела поза початковим переліком |
| [catalog/datasets.json](catalog/datasets.json) | Облік фактично отриманих або створених артефактів |
| `raw/` | Незмінені завантаження; великі файли виключені з Git |
| `processed/` | Відтворювані результати обробки; великі файли виключені з Git |
| `samples/` | Невеликі версійовані приклади для розробки, коли вони з'являться |
| `pipelines/growwhere/` | Реальні адаптери, реєстрація й кеш, формула та просторовий сервіс |
| `pipelines/precompute_maps.py` | Явна підготовка версійованих історичних карт; клієнт не запускає цей job |
| `processed/map-products.sqlite3` | Локальні незмінні продукти карт і RTree; походження та SHA-256 входів у manifest кожного продукту |

Готові карти є похідним дослідницьким результатом реальних джерел. Сценарії,
одиниці, покриття, оновлення й команди відтворення: [prepared-maps.md](../docs/prepared-maps.md).
Сирі входи обліковано в `catalog/datasets.json`, версії похідних продуктів —
у manifest SQLite. Наявність карти Північної Америки не означає наявності
повних придатних для індексу даних на всьому континенті.

## Каталог джерел

`id` — стабільний ключ; `name` — назва; `group` — секція наданого тексту;
`signals` — пошукові ознаки; `coverage_as_provided` — географічний орієнтир
із тексту, а не перевірена специфікація; `candidate_use` — потенційна користь;
`status=listed_unverified` — позицію лише перенесено з тексту;
`verified_product_in_use` — конкретний продукт перевірено й підключено;
`partially_connected` — підключено частину складеної позиції (SSURGO, але не STATSGO2);
`source_document` — шлях до першоджерела від кореня проєкту.
Група `space_agency_partner_resources` відтворює секцію вихідного тексту,
а не встановлює організаційну належність постачальника.

Офіційні URL, версії й умови уточнюй під конкретний продукт. Не додавай
неперевірені адреси як установлені точки доступу.

## Контракт реєстру наборів

Структура: `schema_version: "1.0"`, `datasets: []`. Один запис описує один
завантажений або згенерований артефакт. Порожній масив означає відсутність даних,
а не відсутність пропусків у даних.

Для кожного запису вкажи:

- `id`, `title`, `source_ids` — унікальний ID, назва, ключі з `sources.csv` або `additional-sources.csv`; для синтетичного набору допустимий порожній список джерел.
- `kind` — `observation`, `reanalysis`, `forecast`, `model_estimate`, `derived` або `synthetic`; `forecast` позначає прогноз, який потребує перевірки випуску й горизонту; `is_demo` — булевий прапорець демонстраційності.
- `layer` — `raw`, `processed` або `samples`; `path` — локальний шлях від кореня, або `storage_uri` — місце зберігання; для зовнішнього файлу `local_available=false`.
- `product`, `version`, `source_url`, `retrieved_at`, `verified_at` — конкретний продукт, версія, джерело й дати ISO 8601. Для похідного артефакту також `input_dataset_ids`, `pipeline`, параметри/версія обробки.
- `license`, `license_url`, `redistribution_allowed`, `citation` — перевірені умови й атрибуція. Невідомі умови позначай `null`; це не означає дозвіл на публікацію.
- `spatial` — фактичне покриття, CRS, роздільність та одиниці; `temporal` — початок, кінець, часовий крок і часовий пояс.
- `variables` — поля/канали, визначення, одиниці, `nodata` і правила якості; `quality_notes` — обмеження й результати перевірок.
- `sha256` — контрольна сума отриманого файлу для відтворення. Для багатофайлового набору перелічуй файли й контрольні суми в окремому manifest та посилайся на нього.

Незастосовні поля позначай `null` із поясненням; не вигадуй метадані для
заповнення. Для синтетичних прикладів зазначай спосіб генерації та seed,
якщо він використовується. Усі шляхи до артефактів мають відповідати фактичному
місцю зберігання; отриманий зовнішній артефакт не називай локально доступним.

## Додавання набору

Обери регіон, сигнал і конкретний продукт; перевір доступ та умови;
отримай потрібний зріз; перевір вміст і метадані; зареєструй артефакт.
Для повторення завантаження/обробки збережи команду або пайплайн і параметри.
Перед публікацією прикладів перевір право на поширення.
