# GrowWhere 0.2 — реальна карта й дані

Україномовний застосунок із Leaflet 1.9.4, OpenStreetMap та локальним Python API.
Активна сторінка використовує реальні відповіді NASA POWER, USDA SSURGO, CDL та ERS.
Пілотне покриття аналізу — область Канзасу, США. Решта світу доступна як карта.

## Як запустити

Потрібні Python 3.11+ та доступ до інтернету. Додаткові Python-пакети не потрібні.
У Windows двічі відкрийте `Start-GrowWhere.cmd`: скрипт спочатку викликає `py -3 server\server.py --open-browser` (що обходить порожню системну заглушку `python.exe` з Microsoft Store).
Залиште його вікно відкритим під час роботи; закриття зупинить локальний сайт.

Для розробки з цієї папки:

```text
npm start
```

Або напряму: `py -3 server/server.py --open-browser` (Windows) / `python3 server/server.py`. Адреса: `http://127.0.0.1:4173`.
Інший порт — через `PORT`; шлях до Python для npm — через `GROWWHERE_PYTHON`.
Перевірки методики й адаптерів: `py -3 scripts/test.py` (Python: методика, адаптери та готовність планування) та `node --test scripts/*.test.mjs` (Node.js: геометрія, модель і захист інтерфейсу).
Компіляція та встановлення пакетів не потрібні; Leaflet включено локально.
Детальний опис сценарію, формули та кешування для учасників команди: [docs/onboarding.md](../../../docs/onboarding.md).

## Структура

| Шлях | Відповідальність |
| --- | --- |
| `dist/index.html` | Активна оболонка українською |
| `dist/js/live-app.js` | 5-етапний потік (Мета → Територія → Культура → Умови → Результат), швидкі пресети, клієнтський кеш масштабу |
| `dist/js/user-flow.js` | Перевірки переходів, території, площі та розділення історичного/цільового сезонів |
| `dist/js/crop-options.js` | Історичний добір культур в опорній точці без підміни no-data потенційним балом |
| `dist/js/live-map.js` | Лінивий Leaflet, реальні GeoJSON-полігони, точкове й рамкове виділення території |
| `dist/js/area-selection.js` | Геометрія контуру, площа в га, площово-зважений колір та усереднення 7 чинників |
| `dist/js/live-i18n.js` | Український словник для 7 культур, чинників, станів і опорного історичного календаря |
| `dist/styles.css`, `dist/live.css` | Дизайн у палітрі логотипа GrowWhere (`#27D39B` + `#0B0F0E`), адаптивність, режим `A+` |
| `dist/vendor/` | Leaflet 1.9.4, локальні ресурси та ліцензія |
| `server/server.py` | Локальний HTTP API й статичні файли |
| `../../../data/pipelines/growwhere/` | Адаптери (POWER, SSURGO, CDL, ERS), багаторівневий кеш, FAO-56 та індекс 7 культур |
| `../../../data/catalog/datasets.json` | Походження отриманих наборів, час, URL і SHA-256 |

Старі `app.js`, `map.js`, `model.js` та `i18n.js` — код початкового demo-макета,
не імпортуються активною сторінкою. Їхні штучні числа не є входами версії0.2.

Сценарій із двома входами: [власна ділянка або пошук території](../../../docs/parcel-workflow.md).

## Планування

Актуальний короткостроковий прогноз і перевірені локальні правила показуються окремо від історичного індексу. До повноти критичних входів дата сівби та норма поливу — «Недостатньо даних». [Контракт і наступні етапи](../../../docs/planning-data.md).

## Метод і оновлення

[Підключення та API](../../../docs/live-data-integration.md),
[формула й обмеження](../../../docs/live-methodology.md),
[покрив CDL](../../../docs/landcover-live.md),
[економіка ERS](../../../docs/economics-live.md).

При зміні культури, року, дати сівби, поливу або карти перераховуються результати.
Відкрита вкладка перевіряє дані кожні5хв; серверний TTL джерел24год,
ручне оновлення має мінімальний інтервал60с для однакового запиту.
Історичні дані можуть залишатись незмінними. Дата отримання не є датою спостереження.

Це дослідницький індекс без польової калібровки. Детальні ґрунтові полігони
не збільшують роздільність клімату. CDL перевіряє піксель у точці, а не всю
площу полігона. Поточний попит не підміняється історичною ціною ERS.
За відсутності обов'язкових даних зона має статус «Без даних».

Кеш і незмінені відповіді лежать у `data/raw/live/` та `data/processed/live-cache/`.
Доступ до джерел не потребує API-ключів. Для OpenStreetMap зберігається атрибуція;
тайли завантажуються лише для перегляду, без масового офлайн-копіювання.

## Онлайн-версія

Site раніше зареєстровано приватним; його ID збережено в `.openai/hosting.json`.
Код не передавався до зовнішнього сховища після відмови автоматичної перевірки.
Ця версія працює локально. Для production потрібне серверне розгортання API:
публікація лише `dist/` залишить карту без аналітичного сервісу.
