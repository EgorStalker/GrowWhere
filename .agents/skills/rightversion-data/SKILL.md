# Робота з даними RightVersion

Якщо ще не прочитано, відкрий кореневі [AGENTS.md](../../../AGENTS.md),
[PROJECT.md](../../../PROJECT.md), [інструкції сфери даних](../../../data/AGENTS.md)
та [контракт метаданих](../../../data/README.md).

- Почни з потрібного сигналу, географії та періоду. Якщо їх не визначено, обмежся пошуком варіантів або явно позначеним demo, не завантажуй глобальні архіви навмання.
- Шукай відповідні рядки в `data/catalog/sources.csv`; перевір наявність потрібного артефакту в `data/catalog/datasets.json` перед новим отриманням.
- Для вибраного джерела перевір офіційний продукт, доступ, покриття, QA, умови використання та цитування. Каталог описує кандидати з наданого тексту.
- Спочатку досліди метадані та малу вибірку. Не завантажуй весь растр або таблицю в текстовий контекст.
- Отримані артефакти зареєструй за контрактом. Для похідних результатів збережи вхідні ID, обробку, одиниці та обмеження; не змінюй сирі файли.
- Перед аналітичним висновком перевір сумісність масштабів, часів та одиниць. Для моделі опиши валідацію й невизначеність; індикатори стресу не прирівнюй до агрономічної причинності.
- Для передачі сайту підготуй компактний контракт і, коли потрібно, невеликий позначений приклад; підключай сферу коду тільки для зміни самого застосунку.
