# GrowWhere — вхід для ШІ-агентів

Це головна точка входу в продукт **GrowWhere** команди **RightVersion**
для завдання **Field Shift: Adapting Farms with NASA Data**.
Спілкуйся з командою українською; ідентифікатори коду та даних пиши англійською.

## Початок кожного завдання

1. Прочитай [PROJECT.md](PROJECT.md) — короткий спільний контекст і невизначені рішення.
2. Визнач потрібну сферу за таблицею нижче. Відкрий її `AGENTS.md` та лише відповідний `SKILL.md`.
3. Далі читай конкретні файли, потрібні для завдання. Спершу шукай назви/ідентифікатори, потім відкривай знайдене.
4. Якщо завдання перетинає сфери, додай інструкції другої сфери й потрібний контракт. Не завантажуй усі сфери наперед.

| Завдання | Робоча сфера та її інструкції | Навичка |
| --- | --- | --- |
| Сайт, інтерфейс, API, код, перевірки застосунку | [apps/web/AGENTS.md](apps/web/AGENTS.md) | [rightversion-web](.agents/skills/rightversion-web/SKILL.md) |
| Опис продукту, вимоги, дослідження, рішення, презентаційні тексти | [docs/AGENTS.md](docs/AGENTS.md) | [rightversion-docs](.agents/skills/rightversion-docs/SKILL.md) |
| Пошук джерел, отримання й обробка даних, геоаналіз, ознаки та моделі | [data/AGENTS.md](data/AGENTS.md) | [rightversion-data](.agents/skills/rightversion-data/SKILL.md) |
| Зміна інструкцій або маршрутизації агентів | Цей файл, `PROJECT.md` і лише інструкції змінених сфер | Навичка потрібна лише для відповідної сфери |

Шляхи в таблиці відносні до кореня репозиторію. `AGENTS.md` у вкладених папках
доповнюють ці правила в межах своєї папки. Навички — інструкції виконання,
а факти про продукт, рішення та дані зберігаються у відповідних документах.

## Межі контексту

- Не читай рекурсивно всі файли репозиторію, всі навички, весь каталог ресурсів або всі сирі дані.
- Великі таблиці, растри й часові ряди досліджуй через метадані, вибірки та інструменти; не вставляй їх повністю в контекст.
- Першоджерело ресурсів читай лише для перевірки конкретної позиції. Для пошуку спочатку використовуй каталог у сфері даних.
- Якщо середовище не підхопило локальну навичку автоматично, відкрий її `SKILL.md` за посиланням вручну.
- Для нового окремого агента передай шлях до цього файлу, конкретну мету й межі роботи. Створюй окремих агентів лише коли це доручено або дозволено чинними інструкціями середовища.

## Спільні правила

- Відрізняй підтверджені факти, робочі гіпотези та відкриті питання. Не видавай пропозицію за рішення команди.
- Не вигадуй вимоги хакатону, результати аналізу, властивості наборів або наявність інтеграцій.
- Приклади та синтетичні дані явно позначай як `demo`/`synthetic`, зокрема в інтерфейсі.
- Зміни між сферами узгоджуй через явний контракт: поля, одиниці, просторове й часове покриття, якість та походження.
- Не стверджуй, що NASA підтримує або схвалює RightVersion. Для зовнішніх джерел перевіряй їхні власні умови використання.
- Не додавай ключі доступу, токени чи особисті налаштування в репозиторій.
- Після роботи онови лише зачеплені індекси, метадані або рішення. Повідом результат, перевірки та обмеження.

## Передача завдання

Для продовження іншим агентом залиш коротку передачу: мета; сфера;
потрібні шляхи; що вже зроблено; що перевірено; відкриті питання; наступний крок.
Не копіюй у передачу весь прочитаний контекст.
